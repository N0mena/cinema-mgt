# Cinema management
## 🎬 Cinema Reservation System

A RESTful API for managing a cinema reservation system built with Spring Boot (POJA architecture). The application allows users to browse movie projections, reserve seats, and enables employees and managers to administer movies, projections, and reservations with role-based access control.

### Features
User authentication and authorization
Movie management
Projection (showtime) management
Room and seat management
Seat reservation
Role-based access control
Reservation ownership verification
